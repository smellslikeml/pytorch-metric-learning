# Version 3.1.0

Version 3.1.0 adds AdaFaceLoss. Existing public signatures and the minimum
supported Python, PyTorch, and NumPy versions are unchanged.

## New losses

- `AdaFaceLoss` ([arXiv:2204.00964](https://arxiv.org/abs/2204.00964)) adapts
  the angular and additive margins of a cosine classifier to each sample's
  embedding norm, which serves as a quality estimate: high-norm samples get
  both parts of the margin enlarged, and low-norm samples get a relaxed margin.
  The batch mean and standard deviation of the norms are tracked by exponential
  moving averages that update during training only. With constant norms the
  loss reduces exactly to CosFaceLoss with the same margin and scale. See
  [AdaFaceLoss](../losses/adaface_loss.md).
